# خطة الاختبار

## آلي (قبل أي دمج)
`node tests/run.js` — صياغة كل الملفات، معادلات المسح، العالم بمحاكاة THREE (حتمية، ضفاف، جسور، تصادم مبنى، منطقة عمل هادئة)، ومعرّفات الواجهة.
الاختبار الآلي لا يرى الرسوميات ولا الصوت ولا اللمس، لذلك لا يغني عن القائمة التالية.

## يدوي على الهاتف (بعد كل إصدار)
1. [ ] يُحمَّل العالم بلا شريط أحمر؛ سجّل زمن «🌍 عالم جديد»: ___ ث
2. [ ] منظور الجهاز: تسوية نيفو وقراءة ميرا ✓ كما قبل
3. [ ] الخريطة تُفتح؛ الشبكة كل 100 م؛ النهر والجسور والبيوت ظاهرة؛ لمس نقطة يلتقطها
4. [ ] «مهمة عشوائية» 5 مرات: الجهاز ليس دائماً قرب النهر، والنقاط على الضفة نفسها
5. [ ] حامل الميرا يعبر النهر عبر الجسر
6. [ ] ⚙️ إعدادات ← «🚁 محاكاة الدرون»: يظهر القسم، تعديل `bbTotal` و`OS` يُحفظ بعد إعادة التحميل
7. [ ] 🚁 إقلاع: منظور 🎮 يُظهر شاشة جهاز التحكم وبثّ الكاميرا
8. [ ] صوت الدرون يعمل بعد الإقلاع (الرمز 🔊 وليس 🔊~)؛ تغيير `bbTotal` يُسمع حياً
9. [ ] الاقتراب من بيت يدفع الدرون ولا يدخله؛ الهبوط على سطح بيت ممكن
10. [ ] البطارية تنقص؛ عند 20% عودة تلقائية؛ «🔋 بدّل» يشحنها
11. [ ] 🎞 سجل: إعادة التشغيل تعرض مسار الميرا والجهاز والدرون؛ CSV يُنزَّل
12. [ ] لا تباطؤ ملحوظ في منظور الجهاز بعد إغلاق الدرون
