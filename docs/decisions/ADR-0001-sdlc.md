# ADR-0001 — اعتماد SDLC خفيف وتجميد سكربتات الترقيع

- **التاريخ:** 2026-10-23
- **السياق:** المشروع نما عبر سكربتات ترقيع متراكبة (v3–v10) تعتمد على مراسي نصية داخل ملفات ضخمة؛ تتعطل بسهولة، ولا يوجد ما يكشف التراجعات، وسيشارك ذكاء ثانٍ أقل قوة.
- **القرار:**
  1. `public/` داخل git هو المصدر الوحيد للحقيقة؛ تُجمَّد `patch-v*.js` و`patch/` في `archive/`.
  2. بوابة آلية `node tests/run.js` قبل أي دمج.
  3. العمل عبر بطاقات مهام صغيرة بقبول واضح؛ الذكاء الثاني ينفّذ المهام المعزولة، وClaude يصمّم ويراجع الأجزاء الصعبة.
  4. وثائق (`REQUIREMENTS`, `ARCHITECTURE`, `BACKLOG`, `TEST-PLAN`) قصيرة وحيّة، و`API.md` مولَّد من الكود.
- **النتائج:** تكلفة إعداد مرة واحدة؛ مقابل ذلك تراجعات أقل وتسليم أنظف. الدين المتبقي الأكبر: تقسيم `main.js` (B-003).
