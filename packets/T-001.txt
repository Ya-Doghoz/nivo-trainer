=== AGENTS.md ===
# تعليمات لأي ذكاء اصطناعي يعمل على هذا المشروع

مشروع: مدرّب أجهزة المسح ثلاثي الأبعاد (نيفو/تيودوليت/تاكيومتر/محطة شاملة + درون) — Node + Three.js على Termux. المستخدم عربي.

## قبل أن تبدأ
اقرأ بالترتيب: بطاقة المهمة في `tasks/` ← `docs/ARCHITECTURE.md` ← `docs/API.md` ← الملفات المسموحة فقط.

## قواعد
1. **عدّل فقط الملفات المذكورة في البطاقة.** ممنوع لمس `world.js` و`main.js` و`instrument.js` و`drone-worklet.js` ما لم تذكرها البطاقة صراحة.
2. **لا اعتماديات جديدة ولا تنزيلات ولا خطوات بناء.** ES modules كما هي.
3. **التسليم:** كل ملف تغيّر كاملاً بصيغة `cat > المسار << 'EOF' ... EOF` (المستخدم في Termux)، لا مقاطع جزئية ولا «ضع هذا هنا».
4. **شغّل `node tests/run.js` وألصق نتيجته.** يجب ألا يفشل أي اختبار. لا تقل إنك شغّلت شيئاً لم تشغّله.
5. **المنطق النقي الجديد = اختبار جديد** في `tests/`.
6. **لا تغيّر معادلات `survey-math.js`** دون ذكر قانون المقرر وإضافة اختبار. إن كشف اختبارك خطأً في المعادلة فبلّغ عنه ولا تصلحه بنفسك.
7. **اصطلاحات:** وحدات بالمتر، زوايا بالراديان، `x` شرق و`z` جنوب (الشمال −z)، نصوص الواجهة عربية، لا `Math.random()` في توليد العالم.
8. إن لم يكن الطلب واضحاً فاسأل **سؤالاً واحداً** بدل أن تخمّن.

## شكل ردّك
1. الملفات المعدّلة (قائمة).
2. الملفات كاملة (كتل `cat`).
3. ناتج `node tests/run.js`.
4. كيف أجرّبها يدوياً على الهاتف (خطوات قصيرة).
5. المخاطر أو ما لم تتأكد منه.

| `public/help.js`، `custom.js` | مساعدة القراءة، نماذج Blender المخصصة |

## الجسر بين الوحدات
`window.NIVO` (يُعرَّف في `main.js`، وتضيف إليه الوحدات الأخرى): `sight()`، `cfg()`، `type()`، `say()`، `toast`، `onJobChanged`، `placeInstrument`، `job()`، `half()`، `droneActive/droneRender`، `drone.pos()`، `logbook.event`.
`main.js` يستدعي `NIVO.droneRender()` من `render()` عند فتح الدرون.

## اصطلاحات ثابتة (لا تُكسر)
- الوحدات: **متر**، زوايا داخلية بالراديان.
- الإحداثيات: `x` شرق، `z` جنوب (الشمال = −z). `E = E0 + x`، `N = N0 − z`. السمت 0 = الشمال.
- قراءة الميرا تُحسب **على طول الميرا** (تتأثر بالميلان).
- `groundH(x,z)` تحليلية وهي المرجع للفيزياء؛ شبكات التضاريس للعرض فقط.
- كل عشوائية: `mulberry32(seed * k)`؛ ممنوع `Math.random()` داخل توليد العالم.
- تعقّب الأخطاء المخفية في `instrument.js` (ERR) وتثبيتها لكل بذرة وجهاز.

## العالم
خريطة 1000×1000 م (`HALF=500`)، منطقة عمل هادئة r<90 م، وعورة (جبال/أودية) بعيداً، تضاريس من 3 طبقات (2.4 م / 4 م / 20 م) بتنانير، نهر بموضع عشوائي يتبع انحدار الأرض، جسر لكل تقاطع مع الطريق، بيوت بأبعاد وتصادم (`houseCollide`).

## ديون تقنية معروفة
1. `main.js` ضخم وملتصق بالـDOM — يمنع التطوير المتوازي. (B-003)
2. تاريخ من سكربتات الترقيع (v3–v10): جُمّد في `archive/` ويبقى في git.
3. لا اختبارات متصفح/GPU: التحقق الأخير على الهاتف يدوي (`TEST-PLAN.md`).
4. دفاتر النيفو لا تزال بصيغتها القديمة ولا تستعمل `survey-math.js` بالكامل.

const fs = require('fs'), path = require('path'), os = require('os'), cp = require('child_process');
const root = path.join(__dirname, '..'), pub = path.join(root, 'public');
let pass = 0, fail = 0, warn = 0;
const ok = (m) => { pass++; console.log('  ✓ ' + m); };
const bad = (m) => { fail++; console.log('  ✗ ' + m); };
const wn = (m) => { warn++; console.log('  ⚠ ' + m); };
const near = (a, b, eps, name) => (Math.abs(a - b) <= eps ? ok(name) : bad(`${name}: المتوقع ${b} والفعلي ${a}`));
const files = fs.readdirSync(pub).filter(f => f.endsWith('.js') && !f.includes('.bak') && !f.endsWith('.orig'));
const tmp = fs.mkdtempSync(path.join(os.tmpdir(), 'nivo-'));

  const t = path.join(tmp, f.replace(/\.js$/, esm ? '.mjs' : '.cjs')); fs.writeFileSync(t, src);
  const r = cp.spawnSync(process.execPath, ['--check', t], { encoding: 'utf8' });
  r.status === 0 ? ok(f) : bad(`${f}\n${(r.stderr || '').split('\n').slice(0, 4).join('\n')}`);
});

console.log('2) معادلات المسح (survey-math.js)');
(async () => {
